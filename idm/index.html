Internet Download Manager（简称 IDM）是一款老牌的下载工具，1999 年发布至今，主打多线程分段下载和断点续传。它把一个大文件切成多段同时下载，下到一半断网、关机，重新打开还能从断点接着下。

IDM 能接管 Chrome、Edge、Firefox 等浏览器的下载，点链接自动弹出下载窗口；支持 HTTP、HTTPS、FTP 直链，一份文件最多用 32 条连接同时下，官方标称最高提速 8 倍。

和浏览器自带下载比，IDM 下载器的分段和续传更完整，下大文件不容易半途而废，下载完还能按类型自动归档；和迅雷相比，IDM 下载器走纯工具路线，浏览器接管、视频嗅探、站点抓取更集中。

IDM 下载器支持 Windows 7、8、8.1、10、11，本文系统讲解 IDM 的下载、安装和激活过程，全程实测，电脑小白看完也可能轻松搞定。

添加多个下载任务后，IDM 会自动把它们加入下载队列，按顺序或同时下载。在队列窗口中可以调整优先级、暂停或删除某个任务。

IDM 还支持批量下载相似链接的文件。点击"任务"→"添加批量下载"，输入链接模板（如http://example.com/file(*).zip），设置起始和结束编号，IDM会自动下载所有文件。

IDM新手常见问题

1）安装时别跳过浏览器扩展那一步。扩展没装，浏览器下载不会被接管；如果手滑跳过了，可以在 IDM 的“下载 → 选项 → 常规”里重新触发浏览器集成。

2）IDM 提供 30 天免费试用，装好就能完整使用，试用期内不用做任何额外操作。

3）IDM 只支持 Windows。如果用的是 macOS 或 Linux，装不了 IDM，可以选 Free Download Manager 这类跨平台工具替代。

4）连接数不是越大越好，很多服务器限制同一 IP 的连接数，32 条全开会被拒绝，表现为 403、下载失败或速度反而变慢。
